> **Единственная цель Web2MD-FeedAI — повышение продуктивности: эффективная конвертация выделенных фрагментов веб-страниц или полных статей в чистый, структурированный Markdown, оптимизированный для больших языковых моделей (LLM / ИИ), с возможностью редактирования, предварительного просмотра и копирования в один клик через встроенную боковую панель Chrome.**

## ✨ Ключевые возможности

- 🎯 **Точная конвертация выделения в Markdown (Основная функция)**:
  - Выделите любой текст или таблицу на веб-странице и мгновенно преобразуйте в структурированный GFM Markdown.
  - Всплывающее меню возле курсора: «Копировать MD» или «Открыть панель ↗».
  - **Автоматическая синхронизация с боковой панелью (без помех)**: если боковая панель уже открыта в текущем окне, выделенный контент **автоматически и мгновенно переносится** в панель без всплывающих окон на странице.
  - Автоопределение языка блоков кода (Python, JavaScript, Go, JSON и т.д.) с фильтрацией номеров строк.
  - Преобразование относительных ссылок и изображений в полные абсолютные URL.
  - Сохранение математических формул LaTeX / KaTeX / MathJax (`$formula$` / `$$formula$$`).

- 📊 **Полная совместимость со сложными таблицами**:
  - Поддержка таблиц Slate.js, облачной документации и страниц без `<thead>` или с ячейками `<td class="is-header">`.
  - Преобразование многострочных переносов внутри ячеек в тег `<br>`, исключающее разрушение разметки GFM.
  - Автоматическое оборачивание изолированных строк `<tr>`, если выделена только часть таблицы.

- 🖥️ **Нативная боковая панель Chrome (SidePanel)**:
  - Занимает выделенную область справа, не перекрывая исходную веб-страницу.
  - Поддержка редактирования Markdown и переключения между режимами исходного текста (Raw) и предпросмотра.
  - Подсчет символов и расчет примерного расхода токенов LLM (GPT-4o / Claude 3.5 / DeepSeek) в реальном времени.

- 📰 **Интеллектуальное извлечение статей (Mozilla Readability)**:
  - Удаляет навигацию, баннеры, рекламу и футеры.
  - Извлекает только полезный текст статьи, экономя до 70% токенов контекста ИИ.

- 🧩 **Глубокая поддержка `<iframe>`**:
  - Захват текста внутри междоменных или встроенных фреймов (блоки Notion, интерактивные песочницы).
  - Автоматическая привязка к основному URL и заголовку вкладки для надежного отслеживания источников.

- ⚡ **Копирование в один клик и экспорт**:
  - Кнопки быстрого копирования с тактильной анимацией; экспорт в файлы `.md`.
  - Опциональный переключатель метаданных ИИ (Frontmatter): добавление заголовка, URL и метки времени.
  - **Без конфликтов горячих клавиш**: не регистрирует глобальных сочетаний клавиш.

- 🌍 **Интернационализация (i18n)**:
  - Поддержка 5 языков интерфейса: 🇨🇳 Упрощенный китайский (`zh-CN`), 🇺🇸 Английский (`en`), 🇭🇰 Традиционный китайский (`zh-TW`), 🇯🇵 Японский (`ja`), 🇷🇺 Русский (`ru`).

## 🚀 Установка и запуск (Chrome / Edge)

### 1. Установка из готового архива GitHub Release
1. Перейдите на страницу [Releases](../../releases) и загрузите `Web2MD-FeedAI-v1.0.0.zip`.
2. Откройте Chrome и перейдите в `chrome://extensions/` (или `edge://extensions/` в Edge).
3. Включите **«Режим разработчика»** в правом верхнем углу.
4. Распакуйте архив, нажмите **«Загрузить распакованное расширение»** и выберите папку.
5. Закрепите значок **Web2MD-FeedAI** на панели браузера — расширение готово к работе!

### 2. Сборка из исходного кода
```bash
# 1. Установка зависимостей
npm install

# 2. Сборка проекта в директорию dist/
npm run build

# 3. Запуск автоматических тестов
npm test

# 4. Упаковка архива для Chrome Web Store (в папку release/)
npm run package
```

## 🛠️ Архитектура проекта

```
Web2MD-FeedAI/
├── public/                    # Статические ресурсы (manifest.json, иконки, промо)
│   ├── images/                # Скриншоты и материалы
│   └── icons/                 # Полный набор иконок (16/32/48/128/1080)
├── scripts/
│   ├── build.js               # Скрипт сборки на Vite
│   └── package.js             # Упаковщик ZIP-архива для магазина
├── src/
│   ├── background/            # Сервис-воркер (SidePanel и управление окнами)
│   ├── content/               # Скрипты страницы (iframe, выделение, всплывающие подсказки)
│   ├── sidepanel/             # Интерфейс нативной панели (редактор, предпросмотр)
│   └── utils/
│       ├── html2md.js         # Движок Turndown и оптимизация таблиц/кода
│       ├── readability.js     # Очистка статей Mozilla Readability
│       ├── token.js           # Оценка токенов LLM и символов
│       └── i18n.js            # Движок интернационализации на 5 языков
├── test/
│   └── verify.js              # Набор автоматических тестов
├── dist/                      # Скомпилированные файлы расширения
└── release/                   # Готовые пакеты ZIP для публикации
```
